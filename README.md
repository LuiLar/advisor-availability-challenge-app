# Advisor Availability App
This is a simple web application that allows users to check the availability of advisors. The app is built using React for the frontend and Node.js for the backend. It uses a mock database to store advisor information and their availability.

### Features
- Responsive design that works on both desktop and mobile devices.
- Light and dark mode toggled from your OS settings.
- View a list of advisors and their availability.
- Wait 30 seconds to see telephone and chat availability for each advisor.

### Installation
1. Clone the repository:
```bash
git clone https://github.com/LuiLar/advisor-availability-challenge-app.git
```
2. Navigate to the project directory:
```bash
cd advisor-availability-challenge-app
```
3. Install dependencies for both frontend and backend:
```bash
npm install
```
4. Rename `env.example` to `.env`

5. Start the application:
```bash
npm dev
```
6. Open your browser and navigate to `http://localhost:3000` to view the app.
